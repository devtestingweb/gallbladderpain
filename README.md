## 1. Put it on GitHub Pages (free)

1. Create a free account at github.com.
2. Click **New repository**. Name it `gallbladderpain`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**. Unzip the site on your computer, then drag **everything inside the folder** (not the folder itself) into the upload box. Click **Commit changes**.
4. Go to **Settings > Pages**. Under "Build and deployment", choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. After a minute or two your site is live at `https://YOUR-USERNAME.github.io/gallbladderpain/`.

## 2. Connect gallbladderpain.org

1. The site already includes a `CNAME` file set to `gallbladderpain.org`.
2. In GitHub: **Settings > Pages > Custom domain**, type `gallbladderpain.org`, and save.
3. At your registrar, add the DNS records GitHub shows you (four `A` records for the root domain, and a `CNAME` record for `www` pointing to `YOUR-USERNAME.github.io`).
4. Once it's working, tick **Enforce HTTPS**.

## 3. Connect your email sign-up form

1. Sign up for MailerLite or Kit (both have free plans) and create a form and a welcome email that delivers the Fridge Guide PDF.
2. Set the form's "after sign-up" page to `https://gallbladderpain.org/thank-you/`.
3. Open `assets/js/site.js` and fill in the `OPTIN` block with your form's address. Instructions for both providers are in the file. (Or send the details to Claude and it'll do this for you.)

Until this is done, the forms show a "test mode" message.

## 4. Set your banner ad

Open `assets/js/site.js` and change the `BANNER` block: the link to your sales page, the headline, text and button. Every page updates at once. Set `enabled: false` to hide it.

## 5. Tell Google about the site

1. Add the site to **Google Search Console** (search.google.com/search-console) and verify it.
2. Submit `https://gallbladderpain.org/sitemap.xml` under **Sitemaps**.
3. Optional: add Google Analytics 4.

## Writing new articles

Read `_build/WRITING_RULES.md` first. It sets the voice (simple, no em dashes), length and structure for every article.

## Adding new pages

The pages are generated by a small Python script in `_build/`. Each food guide is one function in `_build/pages_foods.py`. After adding one, list it in `_build/build.py` and run `python3 _build/build.py`. Ask Claude to write and add new food guides for you; it will keep the header, footer, sign-up box and schema consistent.

If your domain isn't `gallbladderpain.org`, change `SITE_URL` in `_build/layout.py` and rebuild.
